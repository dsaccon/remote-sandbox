# Spot as a first-class CLI concept — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make spot a symmetric, discoverable CLI choice — per-launch `--spot`/`--no-spot` flags on `up`, a `sandbox spot on|off|status` default toggle, and a `MARKET` column in `list`.

**Architecture:** Pure Bash CLI over the AWS CLI. A generic `config_write_key` helper in `lib/config.sh` persists the toggle; `bin/sandbox-spot` is a new subcommand auto-routed by the existing generic dispatcher; `bin/sandbox-up` gains a tri-state spot override; `bin/sandbox-list` reads `.InstanceLifecycle` (already present in its describe-instances JSON) for a new column.

**Tech Stack:** Bash, AWS CLI v2, jq, bats (unit tests), shellcheck (lint).

## Global Constraints

- **Test runner:** `bats test/unit` (or one file, e.g. `bats test/unit/config.bats`). `bats` is **not** installed on the dev laptop by policy — run the suite in the sandbox or CI, not on the laptop. `jq` and `shellcheck` are available locally.
- **Lint:** `make lint` runs `shellcheck -x` over all shell files; it must pass.
- **Style:** match the surrounding code — `set -euo pipefail`, `source "$REPO_ROOT/lib/..."`, `die`/`log_info`/`log_warn` from `lib/log.sh`, two-space option help blocks.
- **Precedence (unchanged contract):** per-launch flag > `SANDBOX_*` env > `./config` > built-in default.
- **No new dependencies.**

```bash
# config_write_key KEY VALUE — rewrite the `KEY="..."` line in ./config in
# place, or append it if absent. VALUE is written quoted. Used to persist
# settings changed from the CLI (AMI_ID after a bake, USE_SPOT toggle, ...).
config_write_key() {
    : "${SANDBOX_REPO_ROOT:?config_write_key: SANDBOX_REPO_ROOT not set}"
    local key="$1" val="$2"
    local cfg="$SANDBOX_REPO_ROOT/config"
    [[ -f "$cfg" ]] || die "no config at $cfg"
    local tmp; tmp="$(mktemp)"
    if grep -q "^${key}=" "$cfg"; then
        sed -E "s|^${key}=.*|${key}=\"${val}\"|" "$cfg" > "$tmp"
    else
        cp "$cfg" "$tmp"
        printf '\n%s="%s"\n' "$key" "$val" >> "$tmp"
    fi
    mv "$tmp" "$cfg"
}

# config_write_ami_id NEW_ID — convenience wrapper over config_write_key.
config_write_ami_id() {
    config_write_key AMI_ID "$1"
}
```

- [ ] **Step 3: Create the subcommand**

Create `bin/sandbox-spot`:

```bash
#!/usr/bin/env bash
# bin/sandbox-spot — show or set the standing spot default (USE_SPOT in
# ./config), used by `up` when neither --spot nor --no-spot is given.

set -euo pipefail

REPO_ROOT="${SANDBOX_REPO_ROOT:-$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)}"
# shellcheck source=../lib/log.sh
source "$REPO_ROOT/lib/log.sh"
# shellcheck source=../lib/config.sh
source "$REPO_ROOT/lib/config.sh"

usage() {
    cat <<'EOF'
Usage: sandbox spot [on|off|status]

Show or set the standing spot default (USE_SPOT in ./config). `up` uses this
default when you pass neither --spot nor --no-spot.

  status   (default) Print the current default.
  on       Set USE_SPOT="true"  — future `up` launches request spot.
  off      Set USE_SPOT="false" — future `up` launches on-demand.

Override for a single launch with `sandbox up --spot` / `--no-spot`.
Spot is cheaper but AWS can reclaim it at any time (it terminates the box).
EOF
}

action="${1:-status}"
case "$action" in
    -h|--help)      usage; exit 0 ;;
    on|off|status)  ;;
    *)              usage >&2; die "unknown arg: $1 (try 'sandbox spot --help')" ;;
esac

config_load

case "$action" in
    status)
        if [[ "$USE_SPOT" == "true" ]]; then
            echo "spot: on (USE_SPOT=true)"
        else
            echo "spot: off (USE_SPOT=false)"
        fi
        ;;
    on)
        config_write_key USE_SPOT "true"
        echo "spot: on (USE_SPOT=true) — future \`up\` launches request spot"
        ;;
    off)
        config_write_key USE_SPOT "false"
        echo "spot: off (USE_SPOT=false) — future \`up\` launches on-demand"
        ;;
esac
```

Then make it executable:

```bash

```
